# Afterlife

A pollution simulator for a hackathon. Photograph a piece of rubbish, follow its journey, then watch your pile of buried trash age in a cross-section of the ground.

- Identification runs in the browser (TinyCLIP via Transformers.js). The photo never leaves the device.
- Optional: paste an Anthropic API key to use Claude vision instead (session storage only).
- Persistence figures are ranges with sources; the popular single-number timelines are shown next to them and flagged as unmeasured.

Static site, no build step. Serve the folder or use GitHub Pages.
